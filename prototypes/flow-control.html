Flow control

Version control tracks files. Flow control tracks what your product does. Three changes arrive at once. A text merge accepts all of them. Flow control runs every journey and tells you where changes meet.

1

Three changes

Each was written separately and each looks fine on its own. Pick which ones to merge.

2

What happens when they meet

Every journey is run with no changes, with each change alone, and with the selection merged. Differences that can be explained by one change alone are fine. Where two changes decide the same thing, or something appears only when they are together, it is shown here.

3

Record what should be true

When changes disagree, a person states the intent. That statement is stored and checked from then on, so the same collision is caught next time.

Everything here runs locally. Nothing is sent anywhere.
