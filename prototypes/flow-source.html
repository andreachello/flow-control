Flow source

The flow document is the only thing that is edited. The code files are generated from it and locked. If anyone edits the code directly, a drift check reads it back and stops the change until it is lifted into the flows or thrown away.

1

The flow document

Journeys are ordered steps. Behaviors hold the logic each step uses. Wiring says which event reaches which handler. Edit any of it and the files below regenerate.

2

Generated files

What the machine runs. Read-only. Try editing the code the way a person or an AI agent might, straight in the files.

3

Drift check

The lifter reads the files back into a flow document and compares it with the real one. They must match.

Everything here runs locally. Nothing is sent anywhere.
