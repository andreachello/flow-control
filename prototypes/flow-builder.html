Flow builder

Build a journey out of plain steps. Every step is a real piece of the app, so the journey runs live, shows you what it really did, and tries itself against situations you did not think of.

1

Build the journey

Start from an example or add steps one at a time. Reorder them, remove them, and watch what changes below.

2

Run it live

Pick a starting situation and the journey runs for real. You will see steps you never added, because other steps trigger them.

3

Try to break it

The same journey, run from every starting situation at once. A journey is only finished when the unhappy paths are understood too.

Everything here runs locally. Nothing is sent anywhere.
