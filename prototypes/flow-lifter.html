Flow lifter

Reads the files and recovers the flows, with no AI and no guessing. Same files in, same flows out. Then it checks itself against a real run of the code.

1

Flows from the files alone

Entry points are the functions in the routes file. From each one the analyzer follows every call it can read in the code. Where code reaches another function through an event, it only follows the link if a written rule covers that pattern. Anything else is reported as unresolved, never guessed.

2

Checked against a real run

Each flow below is compared with what the code actually did when the matching journey ran. Disagreements are the interesting part: they show where a rule is missing.

Everything here runs locally. Nothing is sent anywhere.
