Flow tree

A small web app, parsed and run in your browser. Every line has one owner, every journey is traced from a real run, and an AI change is reviewed by what it does to each journey.

1

Every line has one owner

These eight files are the app. A parser splits each one into slices and gives every line exactly one owner. A line it cannot place stays visible as unplaced.

2

Flows come from real runs

Each journey below ran for real, with tracing switched on. The steps are what actually executed, in order, along with the state each one read and changed.

3

Review by behavior

Apply a change written by an AI, then run every journey again. The review shows what each journey now does differently, not which files moved.

Everything here runs locally. Nothing is sent anywhere.
