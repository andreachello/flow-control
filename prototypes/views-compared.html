Every terminal here is real output from flow on the demo app. What do journey and scenario mean?

A journey is something a user does. The terminal calls journeys by their route: POST /api/cancel is Cancel plan, and POST /api/upgrade is Upgrade to Pro. A scenario is a short script that runs a journey and prints what happened. A person writes it once and names it in flow.toml. This one signs in a yearly Pro user, cancels, and prints the plan, interval and header. After flow hook install, Claude Code and Codex pass your request to flow by themselves. This run typed it with --asked.

How to read this

The left column is every file, with the changed one marked. The middle column is what a git diff shows. The right column is what a diff can't show: the only part of the flow this edit touches. Each colored line is a journey, and each stop on it is a function it runs, in call order. A capsule is a function both journeys share, and the red one is the function that changed. Dotted lines are steps left out, the way a diff leaves out unchanged lines. Click a stop to open its code.
